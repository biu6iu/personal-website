# Welcome to my personal portfolio!

This MPA started off as a simple HTML/CSS project two years ago, and has now transformed into a full Astro and Tailwind project, built and deployed automatically through GitHub Actions.  
  
Originally, I intended to build a photography portfolio, but then I got hooked on experimenting with different HTML elements and CSS styling, and one page after another, this became my personal, online resume.
Despite the website looking fairly similar to how it started out as, it has been through two whole refactors, with the first one migrating the website from pure HTML/CSS to Vite.js, and the second one migrating it to
Astro!  

I'm really proud of this website and hopefully I'll be able to add to it as I learn more and more. For now, feel free to have a look through and let me know if you have any questions or recommendations for me :D
